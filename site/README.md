# Публичный сайт pk.management

Статический сайт (шаги 23–26 плана): лендинг, публичные анкеты и подборки,
витрина, правовые страницы. Без фреймворка — `public/` отдаётся как есть,
`build.mjs` (Node ≥ 20, без зависимостей) собирает `dist/` и генерирует
страницы из Supabase, `sitemap.xml` и `robots.txt`.

- Локально: `node site/build.mjs && npx serve site/dist` (или любой
  статический сервер).
- Деплой: workflow «Site Deploy» — при пуше в `main` с изменениями в
  `site/**` собирает и выкладывает на тот же сервер Timeweb в
  `/var/www/site/current`; Caddy отдаёт `pk.management` и `www`.
- Стили повторяют токены приложения (`design_tokens.dart`): белый фон,
  поверхности `#F7F7F5`, радиусы 8/12/16, акцент `#B00000` только у главного
  действия, шрифт Golos Text (подмножество, woff).

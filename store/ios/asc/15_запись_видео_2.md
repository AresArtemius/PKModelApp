# Второе видео для App Review (Guideline 1.2) — 1,5–2 минуты

Нужна сборка 11 (после `git checkout -- . && git pull`, пересборка, TestFlight → обновить).
SQL `modelapp/supabase/sql/ugc_block_safety.sql` должен быть выполнен в Supabase до записи.
Аккаунты: одноразовый `review3@test.ru` (создадим в кадре) и `art@test.ru` (чужие посты/комментарии должны быть в ленте).

Старт записи экрана → запустить приложение с иконки.

1. Экран входа → «Регистрация». На форме регистрации ПОКАЗАТЬ переключатель «Я принимаю документы и согласие на обработку данных» и ссылки под ним («Условия», «Конфиденциальность», «Безопасность детей») — открыть «Условия», пролистать 2 секунды, вернуться. Затем включить переключатель, ввести `review3@test.ru`, пароль, имя → зарегистрироваться.
2. Лента → у чужого поста «⋯» → «Пожаловаться» → выбрать причину → отправить → показать «Жалоба отправлена».
3. Открыть комментарии этого поста → у чужого комментария флажок → «Пожаловаться» → причина → отправить.
4. Тап по имени автора поста → страница аккаунта → «⋯» → «Пожаловаться» (причина → отправить), затем снова «⋯» → «Заблокировать» → подтвердить → назад в Ленту: постов этого автора больше нет (прокрутить, чтобы было видно).
5. Мой аккаунт → вниз → «Удалить аккаунт» → подтвердить (чтобы не оставлять мусор; в кадре не обязательно).

Стоп записи. AirDrop на Mac → Загрузки.

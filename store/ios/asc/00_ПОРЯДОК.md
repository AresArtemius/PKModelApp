# App Store Connect — что куда вставлять (версия 1.1.0)

Сайт: appstoreconnect.apple.com → Приложения → PK Management → Распространение.
Каждый файл ниже = одно поле. Открыть → Cmd+A → Cmd+C → вставить.

## А. Страница версии (слева «Приложение для iOS → 1.1.0 Подготовка к отправке»)

0. Блок «Общие сведения о версии» → поле «Версия» → `1.1.0` (сейчас там 1.0) → «Сохранить».
1. Вкладка «Видео для предпросмотра приложения и снимки экрана» → «iPhone, дисплей 6,9″» →
   перетащить 5 оригиналов с iPhone (Фото → Альбомы → Снимки экрана → AirDrop на Mac → Загрузки).
   Порядок и какие именно — папка `screens_reference/` (1_catalog_filters, 2_profile, 3_castings, 4_feed, 5_chat).
   Файлы из этой папки НЕ загружать — они сжатые, только для сверки.
2. «Рекламный текст»                → `01_promo_text.txt`
3. «Описание»                       → `02_description_ru.txt`
4. «Ключевые слова»                 → `03_keywords_ru.txt`
5. «URL-адрес службы поддержки»     → `04_urls.txt` (строка 1)
   «URL-адрес маркетинга»           → `04_urls.txt` (строка 2)
6. «Сборка» → «Добавить сборку» → 1.1.0 (9) (появится после обработки, 10–20 мин после загрузки из Xcode).
7. «Информация о проверке приложения»:
   «Требуется вход» ✓ → Имя пользователя `art@test.ru`, Пароль — ввести вручную.
   Контактные данные → `05_review_contact.txt`.
   «Примечания»                     → `06_review_notes_en.txt`
8. «Выпуск версии» → «Выпустить эту версию вручную».
9. Справа вверху «Сохранить».

## Б. Слева «Информация о приложении»
- Подзаголовок (русский): `Модели, актёры, кастинги`
- Категория: Основная «Бизнес», Дополнительная «Социальные сети».
- Права на контент → «Да, содержит материалы третьих лиц, у меня есть права».
- Возрастной рейтинг → «Изменить» → ответы из `07_age_rating.txt` → в конце «Переопределение возрастного рейтинга» → 17+.
- Авторские права: `© 2026 PK Management`.
- URL политики конфиденциальности: `https://app.pk.management/#/privacy`
- «Сохранить».

## В. Слева «Конфиденциальность приложения»
«Начать» → ответы из `08_app_privacy.txt` → «Опубликовать».

## Г. Отправка
Страница версии → «Добавить для проверки» → Экспортное соответствие: «Нет» (только HTTPS) → Отправить.

## Д. Второй язык (можно после ревью)
Правый верх страницы версии «русский ▾» → добавить «Английский (США)» → `09_description_en.txt`, `10_keywords_en.txt`, подзаголовок `Models, actors, castings`.

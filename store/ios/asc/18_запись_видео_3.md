# Третье видео для App Review — 1–1,5 минуты (сборка 13, TestFlight → обновить!)

Перед записью в Supabase → SQL Editor должны быть выполнены: `ugc_block_safety.sql`, `account_profile_tags.sql`, `post_reports_update_own.sql`, `blocked_users_list.sql`.
Проверка перед записью (не на видео): под art@test.ru открыть Ленту → тап по имени автора поста → страница аккаунта открывается (не «не найден»).
Аккаунт: `art@test.ru`. В ленте должны быть посты другого пользователя (например admin-аккаунта) с хотя бы одним чужим комментарием.

Старт записи экрана → запустить приложение с иконки (вы уже вышли из аккаунта заранее: Мой аккаунт → Выйти).

1. Экран входа: задержаться 2 сек (внизу ссылки «Условия», «Конфиденциальность», «Безопасность детей») → «Регистрация» → показать переключатель «Я принимаю документы…» → нажать ссылку «Условия» → 2 сек → назад → «Войти» → войти как `art@test.ru`.
2. Лента → у чужого поста «⋯» → «Пожаловаться» → причина → отправить → видна плашка «Жалоба отправлена. Модераторы рассмотрят…».
3. Открыть комментарии этого поста → у чужого комментария флажок → «Пожаловаться» → причина → отправить.
4. Тот же пост → «⋯» → «Заблокировать автора» → в диалоге видно «Его публикации… сразу исчезнут… Модераторы получат уведомление» → «Заблокировать» → ПОСТЫ АВТОРА ИСЧЕЗЛИ ИЗ ЛЕНТЫ, плашка «Пользователь заблокирован…». Прокрутить ленту — его постов нет.
5. Мой аккаунт → карточка «Заблокированные» → в списке автор → кнопка «Разблокировать» → «Разблокировано» (показывает ревьюеру, что блокировка обратима, и возвращает всё как было).

Стоп записи → AirDrop на Mac → Загрузки → переименовать в `pk_review_video_3.mp4` (маленькими буквами!).

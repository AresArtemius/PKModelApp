# Видео для App Review — сценарий (3–5 минут, один дубль не обязателен)

## Подготовка
1. iPhone: Настройки → Пункт управления → добавить «Запись экрана» (если нет).
2. В приложении выйти из аккаунта (Мой аккаунт → Выйти), приложение закрыть полностью.
3. Подготовить ОДНОРАЗОВУЮ почту для регистрации, например `review2@test.ru` (её удалим в конце). `art@test.ru` НЕ удалять!
4. Включить «Не беспокоить», чтобы не всплывали уведомления.

## Запись (шаги подряд)
Старт записи: Пункт управления → кнопка «Запись экрана» → выйти на главный экран.
1. Запустить PK Management с иконки (запись должна начинаться с запуска).
2. Экран входа → «Регистрация» → ввести почту `review2@test.ru`, пароль, имя → зарегистрироваться.
3. Лента: пролистать, открыть пост → «⋯» → «Пожаловаться» → выбрать причину → отправить.
4. Открыть комментарии поста → у чужого комментария «⋯» → «Пожаловаться».
5. Тап по имени автора → страница аккаунта → «⋯» → «Заблокировать» → подтвердить → затем «Разблокировать» (чтобы не ломать данные).
6. Каталог → открыть фильтры → выбрать возраст → «Показать» → открыть анкету (Мия) → пролистать фото, видео.
7. Кастинги → открыть карточку → «Откликнуться» → отклик отправлен.
8. Чаты → открыть чат → отправить сообщение «Здравствуйте!».
9. Мой аккаунт → Настройки → показать «Помощь и поддержка» и юридические документы (одну страницу).
10. Мой аккаунт → Выйти → Войти через `art@test.ru` / пароль → показать, что открылась лента.
11. Мой аккаунт → Выйти → Войти снова под `review2@test.ru` → Мой аккаунт → вниз → «Удалить аккаунт» → подтвердить → приложение вышло на экран входа.
Стоп записи: Пункт управления → «Запись экрана» (или красная полоска сверху → Остановить).

## Отправка
Видео сохранится в Фото. Перекинуть на Mac AirDrop'ом в «Загрузки».
App Store Connect → Приложения → PK Management → слева «Проверка приложения» (App Review) → открыть сообщение от Apple → «Ответить» →
вставить текст из `12_review_reply_en.txt` → кнопка скрепки → приложить видео (.mp4/.mov до 500 МБ; если больше — сжать: Фото на Mac → Файл → Экспортировать → 1080p) → «Отправить».
Затем: страница версии 1.1.0 → «Информация для проверки приложения» → «Примечания» → ДОБАВИТЬ тот же текст из `12_review_reply_en.txt` под существующим → «Сохранить».
Повторно нажимать «Добавить для проверки» не нужно — после ответа проверка продолжится сама.
